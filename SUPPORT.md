# Support

Monad Design is pre-release software maintained on a best-effort basis.

- Use an issue for reproducible bugs and focused feature requests.
- Use a discussion for setup questions, ideas, and broader product feedback if
  discussions are enabled.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities; never disclose them in
  a public issue.

Before asking for help, search existing issues and include the commit, macOS and
Xcode versions, Bun version, relevant logs, and the smallest reproduction you
can provide. Remove local paths, project source, tokens, pairing codes, and
screenshots containing private information.
