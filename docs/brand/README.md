# Monad Design brand assets

## Standard wordmark

[`monad-design-wordmark.svg`](./monad-design-wordmark.svg) is the master standard wordmark. It is traced from the approved raster artwork and contains paths only, so it has no font dependency.

- Preserve the artwork's aspect ratio and internal spacing.
- Use it as a single-color mark. The master is black; override the path fill when an approved alternate color is needed.
- Do not typeset or reconstruct either line with substitute fonts.
