# Agent brand icons

SVG brand marks are vendored from @lobehub/icons-static-svg 1.95.0 (LobeHub,
MIT; git 53ead06d734cc6c003db5a87860907c4bbadfbc0).
https://github.com/lobehub/lobe-icons
They reproduce the respective brands; LobeHub is a third-party distributor.
No generic or generated replacement icons are used.

Additional assets obtained from the official product websites:

- Cline: https://cline.bot/assets/branding/favicons/favicon-256x256.png
- Cursor: https://cursor.com/marketing-static/favicon-light.svg
- Kilo Code: https://kilo.ai/favicon/favicon.svg?v=2
- Zed: https://zed.dev/favicon_black_64.png
- ZCode: https://zcode-ai.com/favicon-48x48.png
- VS Code: https://code.visualstudio.com/assets/apple-touch-icon.png

Brand marks remain the property of their respective owners. These assets identify
supported integrations and do not imply endorsement.
All icons are bundled locally so setup does not make remote image requests.

Render the full-color variants without CSS filters. Brands whose official mark is
monochrome keep that mark. Kimi uses a dark tile so its white lettering remains
visible in both themes; other marks use a light tile.
