# Edge object assets

`bag.png`, `brush.png`, `bulb.png`, `calculator.png`, `calender.png`, `camera.png`,
`can.png`, `chess.png`, `clock.png`, `color-palette.png`, `computer.png`, `glass.png`,
`headphone.png`, `key.png`, `mic.png`, `mobile.png`, `notebook.png`, `paint-kit.png`,
`pencil.png`, `picture.png`, `scissor.png`, `takeaway-cup.png`, `tea-cup.png`, `travel.png`,
`umbrella.png`, and `wallet.png` are Color/Dynamic renders from
[3Dicons](https://github.com/realvjy/3dicons) by Vijay Verma. They are released
under the [CC0 1.0 license](https://github.com/realvjy/3dicons/blob/develop/LICENSE).

These 26 assets are derived from the official 2400 × 2400 transparent PNG originals,
downloaded from [3Dicons V1](https://3dicons.co/collection/b68cf8-v1) on
2026-09-08 with the Dynamic angle and Color style. Desktop and mobile share
these files. Bundled images are resized to 512 × 512 with ImageMagick, stored
as 8-bit-per-channel PNGs, and stripped of metadata with PNG compression level 9.
This covers the current maximum object size (128 CSS pixels on desktop) at
3× pixel density with room for animation scaling, without bundling full-size renders.
The local `paint-kit.png` maps to the provider's `painting-kit`,
and `takeaway-cup.png` maps to `takeway-cup`.

`laptop.png` and `sparkling-water.png` were generated specifically for Monad
Design with OpenAI image generation and have no third-party attribution
requirement.
